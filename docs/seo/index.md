# SEO

## Optimización de sitio web

Mejorar la velocidad de la carga

- Cache de vistas
- Cache de bbdd
- Comprimir imágenes
- Comprimir código css y js

Usar palabras clave en el meta description

Usar un solo h1 por página, debe ser lo más descriptivo posible

Agregar contenido de calidad

Imágenes con atributo alt

Enlaces con atributo rel=”canonical” son más importantes. El atributo title genera una descripción del enlace

Quitar estilos de línea en las etiquetas html

Agregar robot.txt y sitemap.xml para los buscadores de google

## Penalización

Carga lenta del sitio

Contenido duplicado o pobre

Url no amigables

Contenido de golpe y no periódico

Hablar de temas delicados

No tener https

No tener web responsive

Demasiados 404
